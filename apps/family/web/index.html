Life360 only accepts a password here for accounts without a verified phone number. If yours has one, this will fail no matter what you type — use the access token tab instead.

Sign in at life360.com in a browser, open the developer tools, and copy the value of the LIFE360_AUTH_TOKEN cookie. This is what accounts with a verified phone number have to use.

Your password is exchanged for a token once and never stored. Only the token is kept, in apps/family/secrets.json, readable only by you. Life360 has no public API and has blocked outside clients before; if this stops working one day, that is why.
